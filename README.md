# Поиск автозапчастей Favorit

Приложение для поиска автозапчастей по артикулу, просмотра производителей и предложений, включая аналоги.

## Требования

- Node.js
- npm

## Запуск

Установите зависимости:

```bash
npm install
```

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

При необходимости укажите API-ключ в `.env`:

```env
VITE_FAVORIT_API_KEY=your_api_key
```

Запустите приложение в режиме разработки:

```bash
npm run dev
```

Откройте адрес, указанный в терминале Vite.

## Возможности

- Поиск автозапчастей по артикулу.
- Просмотр доступных производителей.
- Просмотр предложений выбранного производителя.
- Отображение аналогов, цен, складов и остатков.
- Сохранение результатов в кэше для сокращения повторных запросов.
- Навигация по страницам с сохранением параметров поиска в URL.

Для автоматического поиска введите не менее трёх символов артикула.

## API

Приложение обращается к API Favorit Parts через маршрут `/api`.

В режиме разработки Vite перенаправляет запросы на:

`https://api.favorit-parts.ru/hs/hsprice/`

Прокси настроен в `vite.config.js` и позволяет отправлять запросы через dev-сервер, в том числе обходить ограничения CORS, если внешний API не разрешает прямые запросы из браузера.

API-ключ задаётся переменной окружения `VITE_FAVORIT_API_KEY`. Переменные с префиксом `VITE_` доступны в клиентской сборке, поэтому используйте только ключ, который разрешено передавать клиенту.
